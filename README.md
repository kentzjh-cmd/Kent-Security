# Kent-Security

个人安全研究与思考。

这个仓库是我一个人的安全笔记本：读过的漏洞、拆过的架构、没想通的问题，以及那些最终被自己推翻的判断。

它不是教程库，也不是漏洞公告的搬运工。它的价值在于**过程**被保留下来了 —— 别人可以沿着我的推理路径重新走一遍，而不是只能接受一个无从追溯的结论。

> 仓库地址：https://github.com/kentzjh-cmd/Kent-Security
> 全部内容为个人学习与研究用途。


## 写作约定

| 约定 | 说明 |
| --- | --- |
| **置信度标注** | 每条结论标注 `verified` / `inferred` / `speculative`，不把猜测写成事实 |
| **保留推翻过程** | 被证伪的结论留在正文里，并注明「已被推翻」及原因 |
| **凭据不入库** | token、口令、内网地址一律不提交，示例一律使用占位符 |
| **时间戳前缀** | 文件名以 `YYYY-MM-DD-` 开头，便于回溯写作顺序 |
| **原始出处** | 涉及 CVE、漏洞公告、论文时附原始链接，不只引用二手解读 |

## 安全底线

- 所有验证只在**自有资产**或**已获书面授权**的目标上进行。
- 不收集、不提交任何真实凭据或个人信息，样本数据一律脱敏。
- 不收录可直接用于攻击真实目标的武器化代码，PoC 以最小可复现和防御视角为主。

## 快速开始

```bash
git clone https://github.com/kentzjh-cmd/Kent-Security.git
cd Kent-Security
cp notes/_template.md notes/$(date +%F)-your-topic.md
```
